# APL253 × NL ↔ [AB | DE | SD] — Complete Digital-Twin Specification

## Formal Grammar

The translation between Natural Language pattern descriptions (NL) and multi-paradigm simulation primitives follows a compositional grammar where each Alexander pattern is expressed as a typed production rule mapping spatial/social/temporal intent to one or more simulation paradigm operators.

### Notation

```
Pattern(id) ::= NL_description → Paradigm_Expression

Paradigm_Expression ::=
  | AB(agent_type, state_machine, spatial_rule)
  | DE(event_type, queue_priority, process_flow)
  | SD(stock, flow_rate, feedback_polarity)
  | AB ⊗ DE(agent_event_coupling)
  | AB ⊗ SD(agent_stock_coupling)
  | DE ⊗ SD(event_flow_coupling)
  | AB ⊗ DE ⊗ SD(full_coupling)

where:
  ⊗  = tensorial composition (interaction/entanglement)
  ⊕  = additive composition (choice/superposition)
  →  = causal production
  ↔  = bidirectional coupling
  ∂  = partial differential (SD rate)
  Δ  = discrete state transition (DE event)
  σ  = agent state function (AB rule)
```

### Paradigm Primitives

| Primitive | Paradigm | Semantics |
|-----------|----------|-----------|
| `spawn(type, pos, state)` | AB | Create agent at location |
| `move(agent, heading, speed)` | AB | Agent locomotion |
| `sense(agent, radius, property)` | AB | Local perception |
| `decide(agent, rule)` | AB | State machine transition |
| `emit(event, time, target)` | DE | Schedule future event |
| `queue(entity, resource, priority)` | DE | Enter service queue |
| `serve(resource, duration)` | DE | Process entity |
| `route(entity, condition, dest)` | DE | Conditional branching |
| `stock(name, initial, bounds)` | SD | Declare accumulator |
| `flow(source, sink, rate_fn)` | SD | Continuous transfer |
| `feedback(stock, polarity, delay)` | SD | Causal loop |
| `diffuse(property, rate, radius)` | SD | Spatial diffusion |

    feedback(cultural_intensity, +, autonomy)
